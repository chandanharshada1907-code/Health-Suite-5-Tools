Mathematical Foundations of Health Metrics

This module highlights how Discrete Mathematics, Set Theory, Logic Proposition Rules, and Matrix Formulations quantify human biological data.

1. Body Mass Index (Quetelet Formula)
\[ \text{BMI} = \frac{W}{H^2} \quad \text{where } W \in \mathbb{R}^+ \text{ (kg)}, H \in \mathbb{R}^+ \text{ (m)} \]

Discrete classification mapping partitions \( \text{BMI} \) into disjoint sets:

  • Underweight: \( S_1 = \{ x \in \mathbb{R} \mid x < 18.5 \} \)
  • Normal: \( S_2 = \{ x \in \mathbb{R} \mid 18.5 \le x < 25.0 \} \)
  • Overweight: \( S_3 = \{ x \in \mathbb{R} \mid 25.0 \le x < 30.0 \} \)
  • Obese: \( S_4 = \{ x \in \mathbb{R} \mid x \ge 30.0 \} \)
2. Basal Metabolic Rate (BMR)
\[ \text{BMR} = 10W + 6.25H - 5A + s \] \[ \text{where } s = \begin{cases} +5 & \text{if male} \\ -161 & \text{if female} \end{cases} \]

Modeled as an affine linear transformation over the vector space of human physical dimensions \( (W, H, A, s)^T \).

3. Propositional Logic Health Rules
\[ (P \land Q) \implies R \] \[ \text{where } P: \text{BMI} > 25, \quad Q: \text{Activity} = \text{Sedentary} \]

Determines risk alerts through truth evaluation matrices on boolean proposition states.

4. Discrete Activity Multipliers
\[ \text{TDEE} = \text{BMR} \times M_{\text{act}} \] \[ M_{\text{act}} \in \{1.2, 1.375, 1.55, 1.725, 1.9\} \]

Maps activity level enum states to scalar multiplication factors in finite set \( M_{\text{act}} \).

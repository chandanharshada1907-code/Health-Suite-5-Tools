Mathematics Behind Goal Tracking

Bounded progress equations, discrete state logic, set operations, and mean statistics.

Discrete Math Model
A. Progress Function
\( P(C,T) = \min\left(100, \left\lfloor\frac{C}{T} \times 100\right\rceil\right) \)

Maps achievement value \( C \ge 0 \) relative to target \( T > 0 \) into clamped interval \( [0, 100] \).

B. Ratio Scaling
\( \text{Ratio} = \frac{\text{Current}}{\text{Target}} \times 100 \% \)

Measures proportional attainment towards finite target boundary condition.

C. State Logic
IF \( C \ge T \):
  Status = Completed, \( P = 100 \% \)
ELSE:
  Status = Active, \( P = P(C,T) \)
D. Sets & Mean Progress
\( G = A \cup C, \quad \mu = \frac{\sum P(g_i)}{|G|} \)

Total goals set \( G \) partitioned into disjoint Active (\( A \)) and Completed (\( C \)) sets with arithmetic mean progress \( \mu \).

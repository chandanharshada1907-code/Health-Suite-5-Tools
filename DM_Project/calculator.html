Mathematics Behind BMI

Discrete mathematical formalization, functional representation, and logic mapping.

Discrete Math Model
1. Functional Representation
\( \text{BMI} = f(W, H) = \frac{W}{H^2} \)

BMI is modeled as a deterministic function \( f: \mathbb{R}^+ \times \mathbb{R}^+ \to \mathbb{R}^+ \) mapping weight \( W \) (kg) and height \( H \) (m) to a unique scalar body mass index value.

2. Arithmetic Operations
  • Unit Conversion: \( H(\text{m}) = \frac{H(\text{cm})}{100} \)
  • Exponentiation: Height is squared (\( H^2 \)) to scale mass relative to body surface area.
  • Division: Weight is divided by squared height (\( W / H^2 \)).
3. Discrete Mathematical Relation
\( (W, H) \xrightarrow{\quad f \quad} \text{BMI Value} \xrightarrow{\quad \text{Mapping} \quad} \text{Category Set } S_k \)

The output codomain is partitioned into mutually disjoint reference subsets: \( S_1 \cup S_2 \cup S_3 \cup S_4 = \mathbb{R}^+ \) and \( S_i \cap S_j = \emptyset \).

4. Propositional Classification Logic
IF Age ≥ 18:
  IF BMI < 18.5 → Underweight
  ELSE IF BMI < 25.0 → Normal Range
  ELSE IF BMI < 30.0 → Overweight
  ELSE → Obesity
ELSE → Pediatric Growth Charts Required
